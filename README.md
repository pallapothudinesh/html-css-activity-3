# 🧠 NexusAI Labs — AI Technology Website

A frontier AI company website designed for **NexusAI Labs**, completed as part of the **Creative HTML & CSS Webpage Projects Activity (Group 3 - Topic #7: AI Technology Website)**.

---

## 🌟 Project Overview
- **Project Topic:** Group 3, Project #7: AI Technology Website
- **Theme:** Cybernetic, deep space dark mode with luminous violet, indigo, and cyan accents.
- **Technologies Used:** Semantic HTML5, Custom Responsive CSS3 (Flexbox & CSS Grid), Vanilla JavaScript (ES6+), FontAwesome Icons, Google Fonts (`Space Grotesk` & `Plus Jakarta Sans`).
